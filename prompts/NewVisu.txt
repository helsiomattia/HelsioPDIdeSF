===========================================================
9. TRANSIÇÃO ENTRE SEÇÕES
===========================================================

Quero uma animação discreta quando uma nova section entra na tela.

A ideia visual é algo semelhante a:

"limpar → escrever → estabilizar"

ou

"wipe → reveal"

SEM parecer apresentação PowerPoint.

Não quero:
- zoom exagerado;
- rotations;
- partículas;
- movimentos constantes;
- parallax pesado;
- elementos voando;
- animações longas.

Quero algo refinado.

Exemplo de sequência:

PASSO 1

A section anterior começa a sair discretamente:

opacity: 1 → 0.92
y: 0 → -10px

PASSO 2

Uma máscara ou clip-path revela a nova seção.

Exemplo conceitual:

clip-path:
inset(100% 0 0 0)
→
inset(0% 0 0 0)

PASSO 3

O conteúdo principal entra:

opacity: 0 → 1
y: 16px → 0

PASSO 4

Cards entram com stagger muito curto:

0.04 – 0.08 segundos

Todo o movimento deve durar aproximadamente:

500ms – 900ms.

Utilizar easings elegantes como:

power2.out
power3.out
power3.inOut

Evitar:

elastic
bounce
